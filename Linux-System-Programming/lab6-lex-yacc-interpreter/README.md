# Lab 6 — Lex/Yacc Interpreter

Учебный мини-интерпретатор арифметических выражений, разработанный на C с использованием Lex/Flex и Yacc/Bison.

Программа выполняет лексический и синтаксический анализ введенных выражений и вычисляет их значения.

## Возможности

- арифметические операции `+`, `-`, `*`, `/`;
- унарный минус;
- использование скобок;
- работа с переменными;
- присваивание значений переменным;
- проверка деления на ноль;
- вызов математических функций;
- таблица символов;
- обработка приоритетов операторов.

## Поддерживаемые функции

- `sqrt()`
- `exp()`
- `log()`
- `sin()`
- `cos()`

## Пример

```text
x = 10
y = 5
x + y
= 15

sqrt(25)
= 5
