# Lab 5 — Lex и этапы компиляции

Учебная работа по изучению этапов компиляции программы на C и основ лексического анализа.

В работе рассматривается процесс преобразования исходного кода C в исполняемую программу, а также используется Lex/Flex для распознавания различных типов констант.

## Лексический анализ

Лексический анализатор распознает:

- строковые константы;
- символьные константы;
- числа с плавающей точкой;
- числа в экспоненциальной форме.
