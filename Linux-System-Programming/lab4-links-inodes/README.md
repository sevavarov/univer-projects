# Lab 4 — Hard Links, Symbolic Links и Inodes

Учебная работа по работе с файловой системой Linux.

В работе рассматриваются жесткие и символические ссылки, inode и системные вызовы для работы с файлами и каталогами.

## Возможности

- создание жестких ссылок;
- создание символических ссылок;
- получение информации о файлах;
- определение файлов с одинаковым inode;
- поиск дублирующих жестких ссылок;
- удаление лишних жестких ссылок;
- работа с каталогами Linux.

## Технологии

- C
- Linux
- POSIX API
- `link()`
- `symlink()`
- `lstat()`
- `unlink()`
- `opendir()`
- `readdir()`

## Как это работает

Программа создает несколько жестких и символических ссылок на файлы в каталоге `input`.

Для определения жестких ссылок используется inode файла. Файлы с одинаковым inode ссылаются на один и тот же объект файловой системы.

После поиска повторяющихся inode программа удаляет лишние жесткие ссылки.

## Основные понятия

**Hard link** — дополнительное имя для существующего файла, связанное с тем же inode.

**Symbolic link** — отдельный файл, содержащий путь к другому файлу или каталогу.

**Inode** — структура файловой системы Linux, содержащая информацию об объекте и используемая для его идентификации.
