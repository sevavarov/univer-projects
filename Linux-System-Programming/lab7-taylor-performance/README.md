# Linux System Programming

Набор учебных проектов по системному программированию под Linux в рамках университетского курса.

Работы выполнены на языке C с использованием POSIX API, механизмов межпроцессного взаимодействия, многопоточности, работы с файловой системой и инструментов Lex/Yacc.

## Содержание

### Lab 3 — IPC и многопоточность

Работа с механизмами межпроцессного взаимодействия и потоками в Linux.

Используемые технологии:

- C
- `fork()`
- `pipe()`
- `read()` / `write()`
- POSIX Threads (`pthread`)
- работа с файлами и каталогами

В работе реализованы варианты обработки данных через канал между процессами и с использованием отдельного потока.

### Lab 4 — Hard Links, Symbolic Links и Inodes

Работа с файловой системой Linux.

Основные задачи:

- создание жестких ссылок;
- создание символических ссылок;
- получение информации о файлах через `lstat()`;
- работа с inode;
- поиск файлов с одинаковым inode;
- удаление дублирующих жестких ссылок.

Используемые системные вызовы:

- `link()`
- `symlink()`
- `lstat()`
- `unlink()`
- `opendir()`
- `readdir()`

Работа с лексическим анализатором Lex/Flex и изучение этапов компиляции программы на C.

- числа с плавающей точкой;
- экспоненциальную запись чисел.

### Lab 6 — Lex/Yacc Interpreter

Мини-интерпретатор арифметических выражений, реализованный с использованием Lex/Flex и Yacc/Bison.

Поддерживаются:

- арифметические операции +, -, *, /;
- унарный минус;
- скобки;
- переменные;
- присваивание значений;
- проверка деления на ноль;
- математические функции.

Доступные функции:

- sqrt()
- exp()
- log()
- sin()
- cos()

Для хранения переменных используется таблица символов.

Используемые технологии:

- C
- Lex/Flex
- Yacc/Bison
- Symbol Table
- парсинг арифметических выражений

### Lab 7 — Taylor Series и измерение времени

Вычисление значения e^x с использованием разложения функции в ряд Тейлора.

Программа позволяет:

- задать количество членов ряда;
- задать значение x;
- вычислить приближенное значение e^x;
- измерить время выполнения вычислений.

Для измерения времени используются Linux API:

- times()
- sysconf()

Технологии

- C
- Linux
- POSIX API
- GCC
- Lex/Flex
- Yacc/Bison
- POSIX Threads
- IPC
- Linux File System API
