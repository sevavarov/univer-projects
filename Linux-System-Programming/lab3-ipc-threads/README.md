# Lab 3 — IPC и многопоточность

Учебная работа по межпроцессному взаимодействию и многопоточности в Linux.

В работе реализованы два подхода к обработке данных:

- взаимодействие между процессами с использованием `pipe()`;
- выполнение обработки в отдельном потоке с использованием POSIX Threads.

## Возможности

- работа с директориями и файлами;
- поиск файлов в заданном каталоге;
- подсчет количества строчных букв;
- определение файлов с минимальным количеством строчных букв;
- передача результатов между процессами через pipe;
- обработка данных в отдельном потоке;
- запись результатов в файл.

## Технологии

- `fork()`
- `pipe()`
- `read()` / `write()`

## IPC

Для межпроцессного взаимодействия используется неименованный канал (pipe).

Родительский процесс выполняет обработку файлов и передает полученный результат дочернему процессу через pipe. Дочерний процесс получает данные и сохраняет результат в файл.

## Multithreading

Во втором варианте обработка выполняется в отдельном потоке с использованием POSIX Threads.

Поток создается с помощью pthread_create(), а завершение его работы ожидается через pthread_join().

## Назначение

Работа демонстрирует базовые механизмы межпроцессного взаимодействия и многопоточности в операционной системе Linux.
