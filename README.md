# University Projects

Учебные проекты, выполненные в рамках обучения по направлению
«Информатика и вычислительная техника» в Самарском университете
имени академика С.П. Королева («Аэрокос»).

Репозиторий содержит проекты по программированию, системному
программированию, клиент-серверному взаимодействию, базам данных,
криптографии и разработке приложений.

## Проекты

### Java

**[Java-Transport](./Java-Transport)**  
Крупный учебный проект на Java, развивавшийся в рамках лабораторных
работ. Включает ООП, обработку исключений, работу с файлами,
сериализацию, коллекции, многопоточность и клиент-серверное
взаимодействие через TCP-сокеты.

**[Java-Calculator](./Java-Calculator)**  
Графическое приложение-калькулятор на JavaFX и FXML.

### C#

**[Lab7-CSharp-Console](./Lab7-CSharp-Console)**  
Консольное приложение на C#.

**[Lab8-CSharp-WindowsForms](./Lab8-CSharp-WindowsForms)**  
Графическое приложение на C# с использованием Windows Forms.

### Системное программирование

**[Linux-System-Programming](./Linux-System-Programming)**  
Набор лабораторных работ на C для Linux. Включает IPC,
многопоточность, работу с файловой системой, inode, hard/symbolic
links, Lex/Flex, Yacc/Bison и системные вызовы Linux.

### Другие проекты

**[AI-Lab5-Neural-Network](./AI-Lab5-Neural-Network)**  
Учебный проект по основам искусственных нейронных сетей.
