# C# Lab 7

Учебный проект на C#.

## Что реализовано

- консольное меню;
- игра на угадывание математических выражений;
- работа с массивами;
- сортировка методом гнома;
- сортировка вставками;
- сравнение времени сортировок;
- обработка строк;
- игра Reversi на поле 9×9;
- ввод и проверка пользовательских данных.

## Технологии

- C#
- .NET 5.0
- Visual Studio
