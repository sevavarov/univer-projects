# Лабораторная работа №8

Windows Forms приложение на C# в рамках учебного курса по программированию.

## О проекте

Приложение объединяет несколько практических заданий в одном Windows Forms интерфейсе:

- работа с математической функцией и игрой на угадывание результата;
- сортировка массива двумя алгоритмами;
- обработка строк;
- реализация игры «Реверси»;
- работа с несколькими формами и элементами Windows Forms.

## Функциональность

### 1. Угадывание результата

Пользователь вводит параметры `a` и `b`. Программа проверяет допустимость введенных значений, вычисляет результат математического выражения и дает пользователю ограниченное количество попыток, чтобы его угадать.

### 2. Сортировка массива

Программа генерирует массив случайных целых чисел и сортирует его двумя алгоритмами:

- гномья сортировка;
- сортировка вставками.

Результаты сортировки отображаются в таблице. Также сравнивается время выполнения алгоритмов.

### 3. Работа со строками

Пользователь может ввести произвольный текст. Программа подсчитывает количество букв `А` и `а` в строке.

### 4. Игра «Реверси»

Реализовано игровое поле размером 8?8.

В игре присутствуют:

- черные и белые фишки;
- чередование ходов;
- изменение цвета фишек;
- подсчет результата игры.
