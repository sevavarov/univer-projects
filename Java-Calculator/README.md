# Java Calculator

Учебное приложение-калькулятор, разработанное на Java с использованием JavaFX и FXML.

## Возможности

- Сложение
- Вычитание
- Умножение
- Деление
- Возведение в степень
- Вычисление квадратного корня
- Работа с десятичными числами
- Последовательное выполнение операций
- Управление с клавиатуры
- Сброс текущего вычисления
- Обработка деления на ноль
- Обработка корня из отрицательного числа

## Технологии

- Java
- JavaFX
- FXML
- Event Handling
