Лабораторная работа №4 по дисциплине «Программирование».

## Задание

Реализовать рекурсивную функцию `F(n)`:

- `F(n) = 1`, при `n < 2`
- `F(n) = F(n // 3) - 1`, если `n >= 2` и делится на 3
- `F(n) = F(n - 1) + 7`, если `n >= 2` и не делится на 3

Программа выполняет две задачи:

1. Находит количество значений `n` на отрезке `[1; 100000]`, для которых `F(n) = 35`.
2. Для введенного пользователем числа `x` вычисляет `F(x)` и определяет количество четных цифр в полученном результате.
