# Лабораторная работа №5 — Нейронная сеть

Лабораторная работа по дисциплине «Системы искусственного интеллекта».

## Описание

В работе реализована и исследована нейронная сеть для классификации образцов итальянских вин.

Используется датасет Wine из `scikit-learn`, содержащий 13 признаков и 3 класса вин.

## Что реализовано

- загрузка и подготовка датасета Wine;
- стандартизация входных данных;
- преобразование целевых классов в категориальный формат;
- построение многослойных нейронных сетей;
- сравнение архитектур с одним и двумя скрытыми слоями;
- обучение с использованием различных оптимизаторов;
- исследование зависимости качества модели от размера обучающей выборки;
- исследование зависимости качества от количества эпох;
- исследование влияния Dropout;
- оценка Accuracy, Precision, Recall, True Positives и False Positives;
- расчёт F1-меры;
- построение ROC-кривых и оценка AUC;
- построение матриц ошибок.

## Используемые технологии

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Keras
- TensorFlow
- Scikit-plot

## Результаты

В работе проведено сравнение моделей с одним и двумя скрытыми слоями, а также исследовано влияние размера обучающей выборки, количества эпох и Dropout на качество классификации.

### Вывод

Исходя из полученных результатов, лучшей моделью является модель с двумя скрытыми слоями, обученная алгоритмом Adamax.
