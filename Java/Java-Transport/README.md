# Java Transport Client-Server

Учебный Java-проект, развивавшийся в рамках серии лабораторных работ.

Проект начинается с реализации моделей транспортных средств и постепенно расширяется до работы с исключениями, сериализацией, коллекциями, многопоточностью и клиент-серверным взаимодействием через TCP-сокеты.

## Возможности

- Интерфейс `Vehicle` для работы с транспортными средствами
- Реализация автомобилей и мотоциклов
- Работа с моделями и их ценами
- Пользовательские исключения
- Переопределение `toString()`, `equals()` и `hashCode()`
- Глубокое клонирование объектов
- Сериализация объектов
- Работа с коллекциями Java
- Reflection API
- Многопоточность
- Клиент-серверное взаимодействие через TCP-сокеты
- Передача массива транспортных средств между клиентом и сервером
- Расчет среднего арифметического цен моделей на сервере
- Последовательная и параллельная обработка подключений

Клиент-серверное взаимодействие

Клиент создает массив транспортных средств и передает его серверу через TCP-соединение.

Сервер получает объекты, рассчитывает среднее арифметическое цен всех моделей и отправляет результат обратно клиенту.

Предусмотрены два варианта сервера:

Server1 — последовательная обработка одного подключения
Server2 — обработка нескольких подключений в отдельных потоках
Запуск

Сначала необходимо запустить один из серверов.

Последовательный сервер
java SequentialServer

После этого запустить клиент:

java Client
Параллельный сервер
java ParallelServer

После запуска сервера клиент можно запускать несколько раз — каждое подключение обрабатывается отдельным потоком.
